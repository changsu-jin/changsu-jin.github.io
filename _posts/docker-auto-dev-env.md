## WMS 개발환경 자동화

WMS가 앞으로 개발도 그렇고, 운영까지 생각해보면 개발자가 많이 늘어날 듯 합니다. 그때마다 매번 개발자들이 환경 세팅하는 게 번거로워 질 것 같아서 도커와 쉘스크립트 이용하여 개발환경을 자동화 했습니다.
특히 요즘 같은 재택이나 원격근무시에는 개발환경 세팅에 가이드도 어렵구요.

WMS 개발환경 자동화는 도커컨테이너에서 빌드 수행하는 형태이며, 개발자들이 개발환경을 따로 세팅하지 않고 쉘스크립트(init.sh) 하나만 실행하면 바로 개발 진행할 수 있도록 모든 개발빌드 환경을 컨테이너에 세팅되도록 하였습니다.

DB도 역시 컨테이너로 같이 생성됩니다.

자동화 된 개발환경은 vscode등의 ide로 도커컨테이너 attach해서 바로 원격 개발 가능합니다.

개발환경 자동화 파일은 아래 저장소에 있습니다.
ssh://git@git-kop.kolon.com:2201/kolon-fnc-wms/wms-dev-container.gitclone받으시면 스크립트 파일 4개 있습니다.init.sh : 최초 실행 파일로 소스클론, 도커이미지빌드, 컨테이너 생성/실행하여 수행 후 바로 웹브라우저에서 주소치고 개발환경 확인 하실 수 있습니다.stop.sh : 실행 중인 도커 컨테이너내 웹서버관련 서비스를 종료합니다.start.sh : 실행 중인 도커 컨테이너내 웹서버관련 서비스를 실행합니다.check.sh : 컨테이너내 웹서버관련 서비스가 종료되지 않고 남은 서비스가 있는지 체크합니다.관심 있으신 분들은 말씀해주시면 해당 프로젝트에 멤버 추가해드리도록 하겠습니다.
